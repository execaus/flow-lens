# Flow Lens

Панель Orca ADE для просмотра плана задачи, текущего этапа и прогресса. Требуется Orca 1.4.248 или новее.

## Установка

В Orca откройте **Settings → Plugins → Install plugin → Git URL**, вставьте `https://github.com/execaus/flow-lens.git#v0.1.2` и включите плагин. Для обновления используйте URL с тегом новой версии.

## Использование

Откройте **Flow Lens** в правой боковой панели, выберите сессию и нажмите **Подключить файл плана**. Отправьте инструкцию из панели в выбранную сессию.

По умолчанию план хранится во временной папке вне репозитория. Если агент может писать только в рабочую папку, добавьте строку `/.flow-lens/` в локальный файл исключений Git и нажмите **Использовать папку проекта**. Из корня worktree:

```sh
printf '\n/.flow-lens/\n' >> "$(git rev-parse --git-path info/exclude)"
```

## Локальный запуск

Добавьте папку плагина через **Settings → Plugins → Development folders…** или выполните `orca plugin dev load .` из корня плагина. Сборка не требуется. Для проверки манифеста используйте `orca plugin validate .` и `orca plugin inspect .`.
